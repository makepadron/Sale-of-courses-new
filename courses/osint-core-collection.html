OSINT Core Collection: базовый инструментарий

Компактная программа для знакомства с основными инструментами OSINT. Материал помогает понять назначение популярных сервисов, научиться выбирать подходящие средства для разных задач и выстроить базовый рабочий набор исследователя.

О программе

В OSINT важно не количество установленных программ, а понимание того, какую задачу решает каждый инструмент, какие данные он использует и насколько надёжны полученные результаты. Эта программа знакомит с основными категориями инструментов и принципами их применения.

Категории инструментов

  • Поисковые системы и расширенный поиск.
  • Поиск по именам пользователей и псевдонимам.
  • Sherlock, Maigret и WhatsMyName.
  • Проверка публичных профилей и цифровых идентификаторов.
  • Поиск информации о доменах и DNS.
  • Инструменты исследования IP-адресов.
  • Сервисы анализа веб-технологий.
  • Веб-архивы и просмотр старых версий сайтов.
  • Поиск и обратный поиск изображений.
  • Инструменты анализа метаданных файлов.
  • Геопространственные сервисы и картографические источники.
  • Публичные базы данных компаний.
  • Сервисы проверки сертификатов и сетевой инфраструктуры.
  • Инструменты организации заметок и результатов исследования.

Как работать с инструментами

Каждый инструмент рассматривается с точки зрения его назначения, входных данных, основных возможностей и ограничений. Отдельно объясняется, почему результаты одного сервиса необходимо проверять с помощью независимых источников.

Рабочий набор исследователя

Программа помогает сформировать базовый набор средств для первичного исследования: от поиска публичных сведений до проверки доменов, изображений и цифровых идентификаторов. Инструменты сгруппированы по задачам, чтобы не приходилось искать подходящий сервис с нуля при каждом исследовании.

Результат обучения

После изучения программы обучающийся будет понимать, какие категории инструментов существуют в OSINT, для чего они применяются, как выбирать подходящий сервис и как проверять результаты его работы.
